# Практическое задание 1

### Задание 1

Проверьте наличие установленных плагинов:

- `Kotlin Toolchain`
- `Android Design Tools`
- `Native Debugging Support`
- `Compose Multiplatform`
- `Java`
- `Kotlin`
- `Android`
- `Exposed`
- `Jetpack Compose`

Самостоятельно установите недостающие плагины, пользуясь разделом
[Настройка IDE и плагинов](lab1/install-plugins.md).

### Задание 2

Создайте новый проект в **IntelliJ IDEA**, пользуясь методичкой.

### Задание 3

Замените в файле `Main.kt` слово `Kotlin` на ваше имя. Например:

```kotlin
val name = "Kotlin"
```

Станет:

```kotlin
val name = "Степан"
```

Проверьте запуск кода и вывод.

### Задание 4

Пользуясь знаниями Английского языка, или с помощью переводчика, 
самостоятельно изучите режим отладки кода `Debug`. Текст указан 
в комментариях в файле `Main.kt` и в подсказках интерфейса **IDE**.
