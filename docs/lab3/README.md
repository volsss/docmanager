# Лабораторная работа 3:<br/>Классы, коллекции и обработка данных в Kotlin

В этой лабораторной работе объединяются темы объектно-ориентированного программирования 
и обработки коллекций в **Kotlin**. На практике предстоит описать предметную область с 
помощью классов и объектов, организовать хранение данных, а затем выполнить над ними 
поиск, фильтрацию, преобразование и анализ.

**Цель работы** — научиться моделировать простую предметную область средствами **Kotlin**, 
хранить объекты в коллекциях и обрабатывать их с использованием объектно-ориентированных 
и функциональных возможностей языка.
