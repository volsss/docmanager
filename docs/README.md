# docmanager

**`docmanager`** — это учебный проект и практическое руководство по разработке 
кроссплатформенного приложения на базе **Kotlin Multiplatform (KMP)** для 
управления документооборотом на примере автоматизации работы с доверенностями.

**Предмет исследования**: процессы автоматизации создания, обработки и учета 
документов (на примере доверенностей) в гетерогенных программных средах.

**Тема проекта**: разработка многоплатформенного приложения для автоматизации 
документооборота с использованием Kotlin Multiplatform на примере документа 
«Доверенность».

**Методы**: 
- Объектно-ориентированное и многоплатформенное проектирование.
- Разработка пользовательских интерфейсов на основе декларативного подхода (Jetpack Compose).
- Проектирование реляционных баз данных и кроссплатформенного доступа к данным.
- Модульная архитектура для разделения общей бизнес-логики и платформенно-специфичного кода в KMP.

**Цель проекта**: создание многоплатформенного приложения (поддерживающего 
Android и Desktop JVM), демонстрирующего полный цикл разработки 
документ-ориентированных систем: от проектирования базы данных и моделей 
до реализации пользовательских форм и автоматизации генерации документов.

**Результаты**:
- Реализованное кроссплатформенное приложение для платформы Android и настольных компьютеров (JVM).
- Спроектированная структура базы данных (с поддержкой PostgreSQL и H2) и модели данных для работы с документами.
- Набор пользовательских форм и компонентов управления для ввода, редактирования и учета доверенностей.
- Практическое руководство и примеры реализации архитектурных паттернов в Kotlin Multiplatform.

**Область применения**: автоматизация внутреннего документооборота и процессов 
подготовки, хранения и обработки документов в организациях, а также учебные и 
демонстрационные проекты, посвящённые разработке приложений на Kotlin 
Multiplatform.

### Поддерживаемые платформы

Приложение таргетировано на следующие платформы:
- **Android**
- **Desktop (JVM)**
