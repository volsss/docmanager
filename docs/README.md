# docmanager

**docmanager** — учебный проект и практическое руководство по разработке кроссплатформенного приложения на базе **Kotlin Multiplatform (KMP)** для управления документооборотом, на примере автоматизации работы с доверенностями.

**Предмет исследования:** процессы автоматизации создания, обработки и учёта документов (на примере доверенностей) в гетерогенных программных средах.

**Тема проекта:** разработка многоплатформенного приложения для автоматизации документооборота с использованием Kotlin Multiplatform на примере документа «Доверенность».
