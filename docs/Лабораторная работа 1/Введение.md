# Лабораторная работа 1
## Установка и настройка окружения

Разработка программного обеспечения начинается с подготовки инструментов, необходимых для написания, сборки, запуска и отладки программ. Корректно настроенная среда разработки позволяет сократить количество ошибок, упростить работу с проектом и обеспечить воспроизводимость процесса разработки.

В рамках проекта docmanager используется язык программирования **Kotlin** и технология **Kotlin Multiplatform** (KMP). Для работы с ними требуется установить интегрированную среду разработки, настроить необходимые компоненты и создать начальный проект. На этом этапе важно познакомиться с назначением **IDE**, **SDK**, плагинов и инструментов сборки.

## Цель работы

Освоить установку и базовую настройку среды разработки для создания приложения на **Kotlin** с перспективой использования **Kotlin Multiplatform**.

## Задачи работы

- ознакомиться с назначением интегрированной среды разработки (**IDE**) и комплекта средств разработки (**SDK**);
- установить и настроить выбранную среду разработки;
- установить необходимые плагины и компоненты для работы с **Kotlin** и **KMP**;
- создать проект и проверить корректность его конфигурации;
- выполнить запуск созданного проекта.

## Ожидаемый результат

В результате выполнения лабораторной работы должна быть подготовлена рабочая среда разработки, создан и успешно запущен начальный **Kotlin**-проект, который будет использоваться в последующих лабораторных работах.
