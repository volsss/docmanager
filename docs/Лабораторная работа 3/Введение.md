# Лабораторная работа 3

## Gradle, мультипроектные сборки и корутины

По мере развития программного проекта увеличивается количество исходных файлов, библиотек и компонентов. Для автоматизации компиляции, тестирования, подключения зависимостей и организации модулей используются системы сборки. В экосистеме **Kotlin** одним из основных инструментов является **Gradle**, позволяющий описывать сборку с помощью конфигурационных файлов и выполнять её отдельные этапы как задачи.

Помимо организации сборки, приложения часто должны выполнять операции, которые не следует проводить блокируя основной поток: например, обращаться к базе данных или получать данные из внешнего источника. В **Kotlin** для структурированного асинхронного программирования используются **корутины**. Понимание этих механизмов необходимо для построения модульного и отзывчивого приложения **docmanager**.

## Цель работы

Изучить принципы организации **Kotlin**-проектов, основы работы **Gradle** и применение корутин для асинхронного выполнения операций.

## Задачи работы

- освоить пакеты и импорты для организации исходного кода;
- познакомиться с назначением **Gradle** и структурой конфигурации проекта;
- изучить мультипроектные сборки и взаимодействие модулей;
- научиться запускать задачи **Gradle**, подключать зависимости и настраивать репозитории;
- рассмотреть жизненный цикл сборки и роль **Gradle**-плагинов;
- изучить основы корутин, их запуск и управление выполнением;
- понять, как применять асинхронные операции в прикладной логике.

## Ожидаемый результат

В результате работы обучающийся должен понимать структуру **Gradle**-проекта, уметь выполнять основные задачи сборки и подключать библиотеки, а также использовать корутины для организации асинхронных операций без блокирования основного потока.
