# Лабораторная работа 2

## Знакомство с Kotlin

**Kotlin** — современный статически типизированный язык программирования, поддерживающий объектно-ориентированный и функциональный подходы. Он отличается лаконичным синтаксисом, системой типов с контролем `null` и широким набором стандартных средств для обработки данных. **Kotlin** применяется при разработке приложений для JVM, Android и в многоплатформенных проектах.

Для дальнейшей разработки **docmanager** необходимо освоить базовые конструкции языка и научиться применять их при описании предметной области. В этой работе рассматриваются переменные и типы данных, управляющие конструкции, функции, лямбда-выражения, классы, наследование, коллекции и основные конструкции моделирования данных.

Для изучения синтаксиса языка и его возможностей, можно воспользоваться
онлайн-компилятором [Kotlin Playground](https://play.kotlinlang.org/).
Но он не поддерживает интерактивную консоль, поэтому ввод данных ограничен.

В методичке некоторые фрагменты кодов будут даваться в виде "песочницы", чтобы
их можно было сразу запустить, посмотреть результат и редактировать.

Вы также сможете нажать **Open in Playground**, чтобы открывать песочницу в отдельном окне.

## Цель работы

Изучить основные возможности языка **Kotlin** и получить практические навыки написания программного кода, необходимого для последующей разработки приложения.

## Задачи работы
- изучить базовый синтаксис, переменные, типы данных и управляющие конструкции;
- освоить объявление функций, параметры, возвращаемые значения и лямбда-выражения;
- познакомиться с классами, наследованием и интерфейсами;
- научиться создавать и обрабатывать коллекции;
- изучить extension-функции и основные операции преобразования коллекций;
- рассмотреть `enum`, `sealed`- и `data`-классы, а также делегирование;
- закрепить материал на небольших примерах.

## Ожидаемый результат

После выполнения работы обучающийся должен уметь читать и писать базовый код на **Kotlin**, создавать функции и классы, работать с коллекциями и выбирать подходящие конструкции языка для представления данных и поведения программы.
