# Практическое задание

Используя знания, полученные при выполнении Лабораторной работы 4, и разработанное в её рамках приложение, перенесите проект на **Kotlin Multiplatform** (KMP).

Необходимо адаптировать приложение для работы на нескольких платформах, сохранив его основную функциональность, пользовательский интерфейс и архитектурные решения. При переносе следует выделить общую логику приложения и переиспользуемые компоненты в общий модуль (`commonMain`), а платформозависимый код разместить в соответствующих платформенных модулях.

В результате выполнения задания приложение должно собираться и запускаться на выбранных целевых платформах, обеспечивая согласованную работу основных функций.
