# Практическое задание 2

### Вариант 1

Дана температура каждого дня недели. Выведи температуры от понедельника 
до воскресенья, а затем посчитай, сколько дней температура была выше `20`.

### Вариант 2

Даны имя сотрудника, его зарплата и количество отработанных дней. 
Выведи сообщение с этими данными и вычисли среднюю зарплату за день.

Если средняя зарплата больше `100`, выведи `"Высокая зарплата"`, иначе `"Обычная зарплата"`.

### Вариант 3

Для чисел от `1` до `30` выведи каждое число и подпиши его как `"чётное"` или `"нечётное"`.

Для числа `15` дополнительно выведи `"Особое число"`.

### Вариант 4

Дан список из пяти оценок, представленных отдельными переменными. 
Посчитай среднюю оценку.

Выведи среднюю оценку текстом, в соответствии с примером:
```
5 -> Отлично
4 -> Хорошо
3 -> Удовлетворительно
2 -> Плохо
1 -> Очень плохо
```

### Вариант 5

Даны два числа: начало и конец диапазона.

Выведи все числа между ними и вычисли их сумму. Если начало больше конца, 
выбрось исключение.

### Вариант 6

Дана строка с именем пользователя.

Выведи её длину, первый и последний символ, а затем посчитай, сколько в ней гласных букв.

### Вариант 7

Даны имя пользователя и пароль.

Выведи сообщение:

```
Пользователь Alex пытается войти
```

Если пароль правильный — `"Доступ разрешён"`, иначе `"Доступ запрещён"`.

После трёх неправильных попыток выбрось исключение.

### Вариант 8

Дано число.

Выведи таблицу умножения от `1` до `10`. Для результатов больше `50` добавляй 
к строке `"Большое число"`.

### Вариант 9

Даны цена товара, количество и имя покупателя.

Посчитай стоимость покупки. Если сумма больше `1000`, предоставь скидку `10%`.

Выведи итоговое сообщение с именем покупателя.

### Вариант 10

Выведи числа от `20` до `1`.

Для каждого числа укажи, является ли оно чётным или нечётным.

### Вариант 11

Напиши функцию, которая принимает `Int` и возвращает его квадрат.

В `main` вызови функцию для чисел от `1` до `10` и выведи 
только те результаты, которые больше `30`.

### Вариант 12

Напиши функцию, принимающую возраст человека.

Функция должна возвращать:

```
0–12 -> Ребёнок
13–17 -> Подросток
18–64 -> Взрослый
65+ -> Пенсионер
```

Выведи результат вместе с именем человека.

### Вариант 13

Напиши функцию, преобразующую температуру из Цельсия в Фаренгейта.

Формула: `(°C × 9/5) + 32 = °F`

Проверь результат через `if`: если температура ниже `0`, выведи предупреждение.

### Вариант 14

Дана последовательность чисел от `-10` до `10`.

Посчитай отдельно количество отрицательных, положительных и нулевых чисел.

В конце выведи три результата.

### Вариант 15

Дана строка.

С помощью цикла выведи каждый символ и его порядковый номер:

```
0: K
1: o
2: t
...
```

Для первой и последней позиции выведи дополнительное сообщение
(`"ПЕРВАЯ ПОЗИЦИЯ"` и `"ПОСЛЕДНЯЯ ПОЗИЦИЯ"`).

### Вариант 16

Даны два числа и оператор (`+`, `-`, `*`, `/`). Выполни арифметическую операцию.
Если оператор неизвестен — выбрось исключение.

Выведи результат в виде понятной строки.

### Вариант 17

Дан номер часа от `0` до `23`.

Определи:

```
0–5 -> Ночь
6–11 -> Утро
12–17 -> День
18–23 -> Вечер
```

Если число выходит за диапазон, выбрось исключение.

### Вариант 18

Дана строка и символ.

Напиши функцию, которая считает, сколько раз этот символ встречается в строке.

Выведи результат в виде:

```
Символ 'a' встречается 3 раза
```

### Вариант 19

Задай секретное число.

Дай программе пять попыток угадать его. Для каждой попытки выводи:

```
Больше
Меньше
Угадано
```

После пяти неудачных попыток сообщи правильный ответ.

### Вариант 20

Найди сумму чисел от `1` до `50`, но пропусти числа, которые делятся на `3`.

После вычисления выведи, является ли сумма чётной.

### Вариант 21

На ввод поступают:

```
имя
фамилия
возраст
город
```

Сформируй красивое многострочное сообщение с помощью raw string.

Если возраст меньше `18`, добавь предупреждение.

### Вариант 22

Напиши функцию, которая получает число и два значения диапазона.

Функция должна возвращать `true`, если число находится в диапазоне, 
и `false` в противном случае.

Проверь функцию для десяти чисел.

### Вариант 23

Даны пять чисел.

Напиши функцию, которая вычисляет их среднее значение.

Если среднее значение больше `50`, выведи `"Результат выше нормы"`, 
иначе `"Результат в норме"`.

### Вариант 24

Дана строка.

Создай её перевёрнутую версию и выведи обе строки:

```
Исходная: Kotlin
Перевёрнутая: niltoK
```

Если исходная строка пустая, выбрось исключение.

### Вариант 25

Даны два числа — начало и конец диапазона.

Выведи только чётные числа между ними с помощью `step`.

В конце выведи их количество.

### Вариант 26

Даны название товара, цена и количество.

Выведи:

```
Товар: ...
Цена: ...
Количество: ...
Итого: ...
```

Если количество отрицательное, выбрось исключение.

Если итог больше `5000`, выведи предупреждение.

### Вариант 27

Для чисел от `1` до `100` выведи:

```
Fizz 0
```

если число делится на `3`,

```
Buzz
```

если делится на `5`,

```
FizzBuzz
```

если делится и на `3`, и на `5`.

Для остальных выводи `Fizz` и само число.

### Вариант 28

Напиши функцию, которая принимает количество набранных баллов от `0` до `100`.

Переведи результат в категорию:

```
90–100 -> A
75–89 -> B
60–74 -> C
40–59 -> D
0–39 -> F
```

Для недопустимого значения выбрось исключение.

### Вариант 29

Для чисел от `1` до `50` найди:

```
минимальное число
максимальное число
сумму
количество чётных
количество нечётных
```

Все вычисления выполни в одной программе.

### Вариант 30

Создай небольшую программу, которая получает имя человека и три его числовых результата.

Программа должна:

1. Вывести данные человека через шаблонную строку.
2. Посчитать средний результат.
3. С помощью `when` определить категорию результата.
4. Сообщить, является ли средний результат чётным.
5. Выбросить исключение, если хотя бы один результат отрицательный.
