## Переменные

В **Kotlin** для объявления переменной используются ключевые слова `val` и `var`.

`val` (value) — read-only переменная. Запрещает переприсваивание самой переменной, 
но объект, на который она ссылается, может быть изменяемым (`Mutable`).

```kotlin
val list = mutableListOf(1, 2)
list.add(3)                    // можно
// list = mutableListOf(4, 5)  // нельзя
```

`var` (variable) — изменяемая переменная, значение можно менять
многократно.

Тип переменной указывается после двоеточия. Однако **Kotlin** умеет
автоматически определять тип по присвоенному значению — это называется
выводом типов (type inference).

```kotlin
val name = "Анна"  // String — выведен автоматически 
var age: Int = 25  // Тип указан явно 
age = 26           // var можно изменить 
// name = "Мария"  // Ошибка: val нельзя переприсвоить 
```

### Хороший тон

Предпочитайте `val` во всех случаях, когда переменная не должна
меняться. Это делает код безопаснее и понятнее.

Явно указывайте тип, если он не очевиден из контекста или если вы
хотите объявить переменную без начального значения (в этом случае
указание типа обязательно):

```kotlin
val message: String 
message = "Привет" 
```

## Базовые типы данных

В **Kotlin** всё является объектом — примитивных типов нет. Единые
типы покрывают числа, символы, логические значения и строки.

> [!NOTE]
> На самом деле на некоторых платформах компилятор **Kotlin** может 
> использовать оптимизированное примитивное представление во время выполнения.


### Числовые типы

| Тип      | Размер (бит) | Пример значения  |
|----------|--------------|------------------|
| `Byte`   | 8            | `127`            |
| `Short`  | 16           | `32000`          |
| `Int`    | 32           | `2_147_483_647`  |
| `Long`   | 64           | `1_000_000_000L` |
| `Float`  | 32           | `3.14f`          |
| `Double` | 64           | `3.14`           |

По умолчанию целые литералы трактуются как `Int`, а числа с
плавающей точкой — как `Double`. Чтобы явно задать `Long` или `Float`,
используйте суффиксы `L` и `f` соответственно.

### Символы и логические значения

* `Char` — один символ в одинарных кавычках (`'A'`).
* `Boolean` — `true` или `false`. 

## Приведение типов

В **Kotlin** нет неявного расширяющего приведения чисел, как в **Java**.
Вместо этого нужно явно вызывать методы `toByte()`, `toShort()`, `toInt()`,
`toLong()`, `toFloat()`, `toDouble()`.

```kotlin
val count: Int = 10 
val bigCount: Long = count.toLong() // Явное приведение 

val grade: Double = 95.7 
val rounded: Int = grade.toInt()
```

**Kotlin** не делает неявное преобразование при присваивании и передаче аргументов:

```kotlin
val a: Int = 10
val b: Long = a.toLong()
```

Но в арифметических выражениях разные числовые типы могут участвовать вместе, 
и тип результата определяется компилятором:

```kotlin
val a: Int = 10
val b: Long = 20L

val result = a + b // Long
```

## Строки

Строки в **Kotlin** неизменяемы и представлены типом `String`. Доступ к
отдельному символу — через оператор `[индекс]`.

* Обычные строки — заключаются в двойные кавычки, поддерживают
escape-последовательности (`\n`, `\t` и т.д.).
* Многострочные строки (raw strings) — обрамляются тройными
кавычками `""" """`, позволяют включить переводы строк и
произвольные символы без экранирования.

## Условные операторы

**Kotlin** предоставляет традиционный `if-else`, который, в отличие от
многих языков, является выражением — то есть возвращает значение.

## Циклы

### Цикл for

Используется для итерации по любому объекту, предоставляющему итератор. 
Чаще всего применяется с диапазонами (`..`), коллекциями, массивами.

<iframe src="https://pl.kotl.in/8mS_mTc1m"></iframe>

### Диапазоны

Диапазон создаётся оператором `..` и представляет последовательность
значений от начального до конечного включительно. 

Существуют также `until` (исключая конец), `downTo`, `step` (только положительный).

```kotlin
val range = 1..10          // 1,2,...,10 
val halfOpen = 0 until 10  // 0,1,...,9 
val chars = 'a'..'z'       // Диапазон символов 
val reverseEven = 10 downTo 0 step 2 // 10,8,6,4,2,0
```

Проверка принадлежности выполняется оператором `in`.

## Исключения

В **Kotlin** все исключения — наследники класса `Throwable`. Присутствуют 
привычные категории: `Exception` и `Error`. Главное отличие от **Java** — 
отсутствие проверяемых исключений (checked exceptions). Компилятор не требует 
объявлять или ловить исключения, что уменьшает количество шаблонного кода.
