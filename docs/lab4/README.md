# Лабораторная работа 4:<br/>Перечисления, обобщения и дополнительные возможности языка

При разработке программ важно не только описывать объекты и хранить данные, но и 
проектировать код так, чтобы он оставался понятным, безопасным и пригодным для 
повторного использования. Для этого в **Kotlin** предусмотрены специальные средства: 
перечисления `enum class`, ограниченные иерархии `sealed class` и `sealed interface`, 
обобщённые типы и функции, объекты-одиночки, сопутствующие объекты, перегрузка 
операторов и делегирование.

Цель работы — закрепить навыки использования `enum class`, `sealed`-типов, `Nothing`, 
обобщений и ограничений типов, вариативности `in`/`out`, проекций типов, `reified`, 
`object` и `companion object`, перегрузки операторов, `infix`-функций и делегирования 
в **Kotlin**.
